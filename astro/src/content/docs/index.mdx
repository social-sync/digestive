## Why Grimnir?

Grimnir pulls tables from a SingleStore (MySQL-wire-compatible) database,
anonymises and redacts the sensitive columns, and writes the result as Parquet
files plus a manifest — a sanitised, referentially-usable copy of production
data for your dev, staging, and test environments.

<CardGrid stagger>
	<Card title="Anonymise & redact" icon="approve-check">
		Built-in transforms null, mask, replace, and deterministically hash PII
		on the way out — or anonymise the values inside a JSON column while
		keeping its shape. Nothing sensitive ever touches disk.
	</Card>
	<Card title="Relationships survive" icon="random">
		Deterministic hashing is global by default: the same value hashes the
		same everywhere, so foreign-key joins still work in the copy.
	</Card>
	<Card title="Single static binary" icon="rocket">
		Pure-Go, no CGO. Clone, build, and ship one artifact — no runtime
		dependencies.
	</Card>
	<Card title="Config-driven" icon="setting">
		One YAML file with environment-variable substitution for secrets.
		Opt-in per table, per-column transforms, per-table row filters.
	</Card>
</CardGrid>
